# Règles pour l'assistant de code

## Le projet
- Site WordPress d'un festival fictif. On ne modifie que le thème enfant, dans `theme/festival-child/`.
- Thème parent : Twenty Twenty-Five (thème « par blocs »). Couleurs et typographies dans `theme.json`, styles complémentaires dans `style.css`, code PHP dans `functions.php`.

## Interdits
- Ne jamais modifier de fichier hors de `theme/festival-child/` sans le dire et sans que le ticket le demande.
- Ne jamais écrire de mot de passe, de clé d'API, d'adresse de serveur ou de donnée personnelle dans le code.
- Ne pas ajouter d'extension WordPress, de bibliothèque ou de framework sans l'accord de l'enseignant.

## Façon de travailler
- Une branche par ticket. Une modification à la fois, petite.
- Expliquer chaque changement en deux phrases : quel fichier, pourquoi.
- Accessibilité : contrastes suffisants, focus visible au clavier, textes alternatifs, tailles lisibles sur mobile (320 px) comme sur ordinateur (1280 px).
- Si une demande est floue, poser une question plutôt que deviner.
